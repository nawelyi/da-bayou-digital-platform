# Decisiones — primera demo

## D-001 — Entrega estática sin dependencias

**Estado:** aceptada para la demo.

La primera versión usa HTML, CSS y JavaScript sin frameworks ni servicios externos. Permite revisar el diseño inmediatamente, reduce riesgos de instalación y mantiene abierta la decisión de hosting o CMS.

## D-002 — Dirección visual original

**Estado:** propuesta para aprobación.

Se usan fotografía a gran escala, tonos cálidos y estructura editorial como referencia general del sector. La identidad de Da Bayou se diferencia con morado profundo, dorado, crema, serif editorial y un tono enfocado en comida + Gameday. No se copian marca, contenido ni recursos de parrains.com.

## D-003 — Contenido claramente provisional

**Estado:** aceptada para la demo.

Los datos no entregados por el cliente no se inventan como definitivos. El sitio muestra ejemplos de menú y promociones, y marca dirección, horario, contacto y QR como pendientes.

## D-004 — Customer Club sin captura real

**Estado:** aceptada para la demo.

El formulario valida la interacción y confirma visualmente el envío, pero no transmite ni guarda información. La integración se implementará después de elegir plataforma, consentimiento y política de privacidad.

## D-005 — QR después de aprobar la URL

**Estado:** aceptada para la demo.

La versión actual muestra una vista previa no escaneable. El QR definitivo debe apuntar al dominio público final para evitar reimpresión de materiales.
